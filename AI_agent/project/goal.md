# 产品目标

**Sim BIM Agent** 将单栋建筑的图纸、文字、照片、CAD 或带贴图三维网格转成轻量 BIM，供查看、修改与后续分析。不同输入逐步接入，支持状态以实际入口和案例结果为准。

## 当前重点

- 先让目标输入到源 BIM 的完整交付稳定，空间划分、关系与几何自洽。
- Work model 不设国别、规模或固定型号上限；现有图纸主线保留 GPT-6 Sol（`gpt-6-sol`），mesh新路线初期允许6 Sol/6.1 Sol。先验证质量和速度，再降低消耗与依赖。
- 首先让可复用的 harness 充分且必要：模型获得可发现、可读取的依据、明确的当前状态和完成条件，负责感知、证据取舍和合理推断；代码承担计算、几何变换、状态管理与确定性检查。每项模型要求应服务于实际质量判断，避免重复登记、重抄完整状态及无目标检查。
- 2026-10-19已开始mesh首批实现：混合输入、简单斜边源几何、可见宿主回叠和当前证据绑定的范围声明进入共享domain115，runtime31不变。Mesh入口、方法和验收先相对独立，共享通用BIM；局部平面、关系草图和文字一并接入，稳定后整合统一Agent。初版调度员直接自主选工具，mesh worker仍待接入；最高调度员自主判断输入用途、精度和工作组织，不穷举固定流程。实现及验收边界见[当前交接](../reports/2026-10-19_textured_mesh_harness_first_build.md)。
- Mesh以整体外几何与立面外窗准确为优先，未知内部合理即可；当前建筑规模目标5–10分钟，常规建筑15分钟内，目标不等于质量硬截止。共同机制需支持立面匹配、非正交/曲线空间及退台/挑空/露台等跨层变化。先用完整贴图案例，不要求外部缺失补全。完整共识见[当前交接](../reports/2026-10-19_textured_mesh_harness_closeout.md)。
- 单模型与分工是可比较的执行方式，角色数量、组合与模型适配以实际效果为依据。当前6 Sol调度/平面high、立面medium；读图并发采用runtime默认8，保留共享预算和恢复。上次整案配置2并发不构成新的产品限制。
- 2026-10-18用户明确：在既定Lite精度和正确空间关系下越快越好，平面读图回到3–4分钟，约5分钟整案为优化目标。无助于可用精度的额外细化、重复判断和状态传输应精简；漏墙、错拆错并、错宿主及连通错误仍须解决。分工入口目前仍要求有限运行预算，不能把速度目标直接当质量截止。完整交付、独立质量、可重复性和耗时分别报告，不靠人工补步骤达成数字。
- 当前v110已完成一次6 Sol/sm25自主分工整案，不等同稳定成熟。整案迭代暂缓；调度员保留获取完整信息和机动处置的能力，未来从流程和默认信息呈现减负，不以硬隔离限制其判断。正确性在读图阶段解决，合理性在整案阶段解决，角色分配留待讨论。墙厚、10cm规整、回叠及审计契约保留，缓存参数不动。复杂管井、EnergyPlus和完整独立审阅不在本轮。
- 当前小批已完成，开发版domain113只保留有效减负和机械格式修复；6 Sol局部质量通过但3–4分钟目标尚未稳定实现，Haiku/27B存在实质失败，不能提前扩称全图或整案验收。详细版本、比较与未覆盖边界见当前交接。
- 国产替代模型按原生图像输入、工具闭环、速度和整任务成本筛选，不局限27B或本地级。近期DeepSeek/Qwen/MiMo各有北立面单样本通过，平面无主线替代成功结果；最新Go直连复测未出现提前EOF，两平面因预算结束且未交付，MiMo未提交草稿质量失败。连接、格式、预算与质量分开评价，详见[复测记录](../reports/2026-10-19_go_direct_reader_retest.md)。调研或旧测试不自动授权新批次。照片原型的开发代理介入与外部标定继续保留说明。

## 输出与质量取舍

核心产物是源 BIM：空间、物理/抽象边界、门窗、相邻与连通、依据。EnergyPlus 是首个可选下游，几何和物性分别适配、验收。

有足够图纸且要求精细还原时，按实际隔墙表达空间，大开敞空间不能仅因朝向或用途被虚构细分。已授权的简化与后端热区划分独立，不需要先补全全部细节。照片按层成块、混合输入局部细度和自动调整规则仍待讨论，不作为默认政策。

漏墙、多墙、错拆错并、假楼板、漏门窗、挂错墙和连通改变优先处理。现有图纸分工采用 10 cm 规整，也允许有依据地规整明确标注的更细数值，保留原始读数与采用值。自动读整图标注选择步长尚未设计，不以逐点四舍五入代替联动规整。

信息不足时可明确推断、假设与简化，不能把推断当观测或用简化掩盖未完成要求。细度后续调整见 [讨论记录](model_and_input_strategy.md)。

图纸的存在不自动意味着高精度量测。输入可仅表达大致空间关系，调度员按用户意图和具体证据决定处理方式；手绘线长、角度和线宽不自动成为尺寸约束。未知内部细度不以房间数、一窗一房或统一门位评价。

## 验收与研究价值

源 BIM 可用性、输入保真、推断合理性、runtime 可靠性/效率、模型服务与下游仿真分别验收。SOTA 完成某例可作为标杆；harness 是否提高稳定性、速度或经济性仍须实测。

既有 Voimatalo 成果、图纸成功对照和失败证据保留，不冒充当前版本结果。下一步与唯一交接见 [roadmap](roadmap.md)。
