# 有效稿后收尾提速：三项实现与验证

用户授权按上一轮三项方案实施，重点压缩有效稿后的收尾，保留必要质量检查。本轮完成 domain 实现、定向离线验证、正式 MCP 贯通和独立审阅；未调用真实工作模型、未冷启动新整案、未续跑历史任务或发布桌面。

版本：**domain-v132-20261020 / runtime-v36-20261020**。公共 runtime 未修改；共享 domain 工具回执与局部几何规整有变化，图纸和 readonly 相邻入口已覆盖。正常提交推送后工作树收净。

## 已实现

1. **统一非阻断信息的行动。** `room_use_review` 将缺结构化用途记录与真实用途问题分开。已有合理用途但未登记证据，只保留覆盖率；unknown、非目录角色及角色/证据冲突保留定向判断。`closeout.action_state` 与机器阻断、用途判断、正常收尾分支一致。没有增加强制审核登记调用，也没有把未知自动视作通过或硬阻断。
2. **参数编辑入口直接可用。** 保存、inspect 和修改拒绝返回 `edit_route`，包括精确计划哈希、可直接传给 MCP 的 `patch_arguments`、通用编辑字段契约和推荐工具。针对不支持的 `update_opening.kind` 给实际声明路径、局部 patch、共享模板作用范围与尚未转换字段。实例化坐标不会被自动当作模板坐标；作用于整列的修改也不会伪装成单对象修补。
3. **保存时给足增量材料。** 新 `save_facts` 复用源检查和 inference audit，返回实体差异、显式跨层体、实际层门连接及受影响宿主摘要；完整内容位于哈希绑定的可读取报告。`build_parametric_bim`、`patch_parametric_bim`、`revise_bim` 可通过 `mesh_observations` 在同次响应返回指定已有相机的当前稿回叠。`view_mesh(candidate=...)` 将新相机观察与当前回叠合在一次调用中。`inferences_json` 可随保存或 finish 合批保存解释，全部声明先校验再写，不要求额外登记轮次。

保存后的可选反馈或声明失败会明确报告，保留已保存稿及其原有质量状态；finish 上无效声明仍会拒绝。回叠只使用当前源，生成图片不代表已完成模型审阅。保存不自动渲染全部视角，也不自动增加数值精度门槛。

## 修复了真实编辑缺陷

此前第二次通用修改失败不只是模型选错入口。参数连续空间会生成独立核心楼层；转通用修改时该楼层丢失局部坐标框架，一侧宿主被重新按 identity 网格规整，导致同一开口两侧产生偏差。

现按连续空间编译时的参考成员（最低层）继承局部框架，其他成员仍经过既有宿主一致性检查。最小反例验证局部层门修改和后继 notes 修改不会改变原楼层几何、开口 XY 或连接。历史第二次失败操作只读确定性重放已规整通过、0 rejection；没有修改原 run，也没有把重放算作新的模型运行。

## 独立审阅

未参与实现的审阅者检查当前全部变更，发现两项 P2，均已修复并独立复验：

- **大回执隐藏可行动信息。** 普通压缩原本把较长编辑路径与回叠列表变成需要再读的报告引用。现先做专用精简，保留工具/哈希/路径/局部 patch/共享作用范围，以及所有选定 overlay IDs。5 个修改目标、每个涉及 23 层、15 个回叠加大库存的反例约 6.2 KB，必需信息直接可见。新增反馈令原小源检查落出 fallback 的相邻问题也已修复。
- **失败 draft 恢复后丢失差异基线。** 复用已有哈希绑定的 `feedback_parent`，正常祖先标为 `compared / bound_feedback_ancestor`，失效祖先标为 `unavailable`；包括参数层发现祖先失效后的真实错误传递。比较基线不写成源几何父链，不误称初次构建。

最终独审无剩余可操作 P1/P2。另核对两模板、乱序连续成员、不同但等价网格及连续两次 generic 修改：源几何、开口 XY、3 条连接和源检查保持。
